# Directus - MapGrid Layout Extension

> **PT-BR** | [EN](#-en)

---

## 🇧🇷 PT-BR

Extensão de layout para o Directus que exibe o conteúdo de uma coleção simultaneamente em **mapa** e **grade** (grid). Desenvolvida pela [Devix Tecnologia](https://devix.co).

### 💎 Usando a extensão

- Garanta que a coleção possua um campo do tipo **"Map"** e selecione esse campo nas Opções do Layout (campo **Geolocation**).
- Ative o layout no menu de configurações à direita selecionando **"MapGrid"** na lista de layouts.

![Tela da extensão](https://raw.githubusercontent.com/devix-tecnologia/directus-extension-mapgrid/develop/docs/tela.jpg)

### 🚀 Rodando o Directus com Docker Compose

- Baixe este projeto ou copie o arquivo `docker-compose.yml` e inicie uma instalação limpa.
- Com o Docker instalado na sua máquina ([saiba mais](https://docs.docker.com/get-docker/)), execute o comando:

```
docker compose up
```

## 🇺🇸 EN

A Directus layout extension that displays a collection's content simultaneously in **map** and **grid** views. Built by [Devix Tecnologia](https://devix.co).

### 💎 Using the Extension

- Make sure your collection has a field of type **"Map"** and select that field in the Layout Options (**Geolocation** field).
- Enable the layout from the settings menu on the right by selecting **"MapGrid"** from the layout dropdown.

![Extension screen](https://raw.githubusercontent.com/devix-tecnologia/directus-extension-mapgrid/develop/docs/tela.jpg)

### 🚀 Running Directus with Docker Compose

- Download this project or copy the `docker-compose.yml` file and start a fresh installation.
- With Docker installed on your machine ([learn more](https://docs.docker.com/get-docker/)), run:

```
docker compose up
```
